Tonearm 0.3.1 is a stability and security update. It fixes the issues found in an external code audit of 0.3.0. There are no new features, and every preset looks exactly as it did.

## Download

- **`tonearm-v0.3.1-windows-x64.zip`** is the plugin. Close OBS, extract the zip into your OBS folder (usually `C:\Program Files\obs-studio`) and let Windows **merge** the `obs-plugins` and `data` folders. Installing over 0.3.0 or 0.2.0 is fine.
- `tonearm-v0.3.1-windows-x64-pdb.zip` holds debug symbols. You only need it when reporting a crash.

Requires Windows 10 1809 or newer (64-bit) and OBS Studio 30.2 or newer. Full steps are in [Getting started](https://github.com/vatariii/tonearm/blob/main/docs/getting-started.md).

## Fixes

- Very short or narrow cards, such as a 300×80 Editorial card in the Square layout, could read outside the artwork while rendering. They now render safely at every supported size.
- A race between OBS's settings and render threads in animated artwork, a COM reference miscount in Windows text rendering, and missing checks in the Reset size, Export and Import buttons are fixed.
- **Refresh** under Sources now updates the list of detected players.
- A motion video that failed to download is no longer downloaded a second time.

## Animated artwork

- The video cache in `%LOCALAPPDATA%\Tonearm\MotionCache` is now kept to 1 GiB. The least recently played videos are removed first. Videos that are downloading or on screen are never removed, and Tonearm only touches folders it created.
- Redirects are followed only to the lookup service itself, or for videos to Apple's own media servers. Anything else is refused and the still cover stays.
- If the artwork service is down or rate-limiting, Tonearm pauses lookups for a while instead of retrying on every song. Cached albums and local folders keep working.
- Large videos are written to disk as they download, the capture texture is freed when animated artwork is off, and a paused video is no longer copied every frame.

## Testing

The unit tests pass on Linux and on Windows (with DirectWrite), including new tests at the extremes of the size range and for the network and cache rules, and under AddressSanitizer, UndefinedBehaviorSanitizer and ThreadSanitizer on Linux. **This release has not been loaded in OBS on Windows yet**, and the planned 12-hour soak test hasn't run, so please report anything unusual. Details are in [Testing](https://github.com/vatariii/tonearm/blob/main/docs/testing.md) and the [audit disposition](https://github.com/vatariii/tonearm/blob/main/docs/audit/v0.3.1.md).

The full list of changes is in the [changelog](https://github.com/vatariii/tonearm/blob/main/CHANGELOG.md).
